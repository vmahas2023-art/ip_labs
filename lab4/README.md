# Лабораторна робота №4
Магас Віталій Дмитрович, ІП 41.

Тема: Розробка веб-сторінки із формою «Анкета студента».

Усі 15 елементів із методички, section, fieldset, legend, label. Вбудована HTML5-валідація, перевірка типу та обсягу резюме, локальний попередній перегляд. Серверний обробник методичкою не вимагається; форма не надсилає і не зберігає дані. Для перевірки використовуйте лише тестовий пароль і тестове резюме.
