# Лабораторна робота №5
Магас Віталій Дмитрович, ІП 41.

CSS. Робота з блочною моделлю. Інструменти веб-розробки Developer Tools.
Відтворено header#events_container з https://lpnu.ua/ станом на 12.11.2026. На головній сторінці джерела знайдено 5 header: navbar, hero_container, logos_container, featured_container, events_container.

Усі шість афіш та Roboto Condensed збережено локально. Оригінальну вкладену структуру та класи збережено, посилання зроблено абсолютними, datetime виправлено до ISO 8601. CSS містить блочну модель, шрифти, кольори, стани hover/focus й адаптивну сітку.

У браузерному середовищі DevTools заблоковані політикою організації. Тому DOM та обчислені стилі досліджено доступним засобом читання DOM/CSSOM; знімок відмови включено у звіт. Скріншоти панелі Elements не підроблялися.
