## Локальний перегляд

У корені проєкту: `python3 -m http.server 8080`.
Відкрити `http://localhost:8080/` та `http://localhost:8080/lab2/`.
Посилання «Головна» починається з `/`, як вимагає методичка,
тому проєкт слід перевіряти через HTTP, а не подвійним натисканням HTML.

## Структура

- `index.html` — коренева копія меню;
- `lab2/index.html` — виконана сторінка лабораторної №2;
- `lab1/index.html` — явно позначене місце для оригінальної роботи №1;
- `lab3/index.html` — сторінка майбутньої роботи;
- `assets/style.css` — оформлення;
- `netlify.toml` — каталог публікації `.` для статичного сайту.

## Що потрібно для завершення роботи

Оригінальної лабораторної №1 у наданих матеріалах немає.
Потрібно замінити `lab1/index.html` її справжніми файлами.
GitHub-репозиторій має бути приватним і називатися `ip_labs`.
Netlify потрібно підключити до цього репозиторію, а не виконувати ручний
одноразовий upload: завдання вимагає автоматичного розгортання після push.
Публікацію та знімки GitHub/Netlify можна підтвердити лише після входу
в облікові записи студента. У цьому пакеті немає вигаданих URL чи скріншотів.
