Netlify підключено до гілки main. Каталог публікації — корінь проєкту (.). Команда збірки не потрібна.

## Структура

- index.html — головне меню;
- lab2/index.html — сторінка лабораторної №2;
- lab1/index.html — місце для оригінальних матеріалів лабораторної №1;
- lab3/index.html — сторінка майбутньої лабораторної №3;
- assets/style.css — адаптивне оформлення;
- netlify.toml — параметри публікації.

## Локальний перегляд

У корені проєкту виконайте python3 -m http.server 8080 та відкрийте http://localhost:8080/ .

Оригінальні файли лабораторної №1 не надано. Поточна lab1/index.html прямо позначає це і не є виконаною лабораторною №1.
