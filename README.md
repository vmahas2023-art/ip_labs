## Опубліковані сторінки

- Головне меню: https://capable-frangollo-7ab6b0.netlify.app/
- Lab1, картка студента: https://capable-frangollo-7ab6b0.netlify.app/lab1/
- Lab2, меню сайту: https://capable-frangollo-7ab6b0.netlify.app/lab2/

Приватний репозиторій: https://github.com/vmahas2023-art/ip_labs
Netlify автоматично розгортає гілку main. Каталог публікації — корінь проєкту (.). Команда збірки не потрібна.

## Структура

- index.html — головне меню;
- lab1/index.html — виконана картка студента за прототипом з Lab1_.pdf;
- lab2/index.html — сторінка лабораторної №2;
- lab3/index.html — сторінка майбутньої лабораторної №3;
- assets/style.css — оформлення меню;
- netlify.toml — параметри публікації;
- evidence/ — оригінальні знімки виконання.

## Перегляд локально

У корені проєкту виконайте python3 -m http.server 8080. Відкрийте http://localhost:8080/ та перейдіть до Lab1 або Lab2.

Дані про досягнення й рівень мови у картці — позначені навчальні приклади з прототипу.
